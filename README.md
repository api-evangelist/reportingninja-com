Reporting Ninja provides AI‑enhanced, client‑ready marketing reports that integrate data from platforms like Google Analytics, Meta Ads, Google Ads, and many others. Users can build reports via a visual builder, AI assistants such as Claude and ChatGPT, or custom templates, then share, schedule, or white‑label them for clients. The platform offers integrations, a REST API, and a marketing‑focused MCP connector, targeting agencies, freelancers, and in‑house teams.

**Areas:** Marketing reporting · AI reporting · Data integration · White label · Client portal · Cross‑channel reporting

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Reporting Ninja: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
